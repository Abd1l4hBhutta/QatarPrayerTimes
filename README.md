# Qatar Prayer Times 🇶🇦

An Android prayer times app designed specifically for Qatar, providing accurate daily Salah times based on the official timings from [prayers.qa](https://prayers.qa).

### Features

* Accurate prayer times for Qatar
* Daily Salah schedule
* Clean and simple Android interface
* Built specifically for users in Qatar
* Easy access to today's prayer timings

This project was created as an Android implementation of a Qatar-focused prayer time experience, with prayer timings sourced from prayers.qa.
